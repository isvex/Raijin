## 🚀 Get started

### [Download the latest Raijin for Windows x64](https://github.com/isvex/Raijin/releases/latest)

1. Download and run the **Raijin-Setup** installer from the latest release.
2. Follow the welcome steps and optionally import bookmarks and history.
3. Make yourself at home — choose your tab layout, theme and privacy preferences in Settings.

**Requirements:** Windows x64, build 19045 or later. Setup includes the private .NET runtime when needed and checks Evergreen WebView2. Internet access may be needed for prerequisites, protection lists and updates. **Free to use; no Raijin account or subscription required.**

## 🔄 Updates made simple

Compatible releases are downloaded and signature-verified in the background. When an update is ready, choose **Restart now** (your tabs are saved), or close all Raijin windows and reopen. You normally do not need to run the installer for each update.

<details>
<summary><strong>ℹ️ Notes</strong></summary>

- The installer does not carry an Authenticode publisher certificate. Browser updates use a separate authenticated signature system. Keep Windows security protections enabled.
- Extension compatibility depends on supported APIs. Local extensions without a verified Store source require manual updates.
- Site-specific video/ad behaviour depends on upstream filter rules and website changes; universal parity with other blockers is not claimed.
- Release notes and checksums for every version are on the [Releases](https://github.com/isvex/Raijin/releases) page, along with the corresponding open-source notices.
